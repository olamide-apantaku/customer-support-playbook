# Customer Onboarding Checklist

A comprehensive checklist for onboarding new customers 
across fintech, telecom and BPO support environments. 
Designed to ensure every customer has a smooth, 
consistent and positive onboarding experience.

## Pre-Onboarding
- [ ] Confirm customer details are complete and accurate
- [ ] Verify all required documents are submitted
- [ ] Confirm account type and service package selected
- [ ] Assign dedicated support agent if applicable
- [ ] Send welcome email with onboarding instructions
- [ ] Set up customer profile in CRM
- [ ] Flag any missing information before proceeding

## Account Setup
- [ ] Create customer account in system
- [ ] Assign unique customer ID
- [ ] Set correct account tier and permissions
- [ ] Link all relevant contact details
- [ ] Set communication preferences — email, phone, chat
- [ ] Enable relevant product features for account
- [ ] Confirm account is active and accessible
- [ ] Document account setup completion in CRM

## Product Walkthrough
- [ ] Schedule product walkthrough with customer
- [ ] Explain core product features clearly
- [ ] Demonstrate how to navigate the platform
- [ ] Explain billing and payment process
- [ ] Share self service resources and FAQs
- [ ] Provide contact details for support
- [ ] Confirm customer understands product usage
- [ ] Answer all customer questions before closing

## Communication Setup
- [ ] Confirm preferred communication channel
- [ ] Add customer to relevant communication lists
- [ ] Set up automated welcome messages if applicable
- [ ] Share support contact details across all channels
- [ ] Confirm customer has received welcome communication
- [ ] Document communication preferences in CRM

## First Interaction Checklist
- [ ] Greet customer warmly and professionally
- [ ] Introduce yourself and your role
- [ ] Confirm customer details and account information
- [ ] Ask open ended questions to understand needs
- [ ] Listen actively without interrupting
- [ ] Provide clear and accurate information
- [ ] Confirm customer is satisfied before closing
- [ ] Document interaction fully in CRM

## KYC and Verification
- [ ] Confirm KYC documents have been submitted
- [ ] Verify document authenticity and validity
- [ ] Confirm selfie or biometric verification if required
- [ ] Check KYC status in system
- [ ] Follow up on pending or rejected KYC immediately
- [ ] Escalate complex KYC issues to compliance team
- [ ] Confirm KYC completion before full account activation
- [ ] Document KYC status and outcome in CRM

## Post-Onboarding Follow Up
- [ ] Contact customer within 48 hours of onboarding
- [ ] Confirm account is working correctly
- [ ] Ask if customer has any questions or concerns
- [ ] Share additional resources if needed
- [ ] Request feedback on onboarding experience
- [ ] Log CSAT score from onboarding interaction
- [ ] Flag any issues raised for immediate resolution
- [ ] Document follow up outcome in CRM

## Common Onboarding Issues

| Issue | Likely Cause | Resolution |
|---|---|---|
| Account not activated | KYC pending or incomplete | Complete KYC verification |
| Login issues | Wrong credentials or system error | Reset password or escalate |
| Missing features | Wrong account tier | Review and upgrade account |
| Document rejected | Wrong format or expired | Request correct document |
| Customer not responding | Wrong contact details | Verify and update details |
| Delayed activation | System processing time | Advise 24-48 hour timeline |

## Onboarding Success Metrics

| Metric | Target |
|---|---|
| Onboarding Completion Rate | 95%+ |
| Time to First Interaction | Within 24 hours |
| KYC Completion Rate | 90%+ |
| Post-Onboarding CSAT | 90%+ |
| First Contact Resolution | 80%+ |
| Follow Up Completion | 100% |
